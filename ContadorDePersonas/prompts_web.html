Prompts e IAs Utilizadas

1. Prompt Original (Borrador)

Mejora este prompt, es para Stitch AI: Tengo que diseñar una pagina web que trate sobre un contador de personas, tiene que tener en cuenta las siguientes caracteristicas: 1- Pantalla, si hay 1 persona tiene que ponerlo en singular, si pone 0 tiene que poner personas 2- Tiene que tener un limite, y debe contar hombres y mujeres 3- Una imagen de fondo, iconos para que sea mas llamativo, etc…

2. Prompt Optimizado (Para Stitch AI)

Actúa como un experto en desarrollo web y diseño UI/UX. Genera el código HTML, CSS y JavaScript para una aplicación web de un "Contador de Aforo". Requisitos de la Interfaz (Visuales): - Diseño moderno, atractivo y completamente responsive (adaptable a móviles). - Pon una imagen de fondo relacionada con eventos o discotecas, aplicando un filtro oscuro (overlay) para que los textos blancos destaquen y sean legibles. - Utiliza iconos vectoriales o de librerías (tipo FontAwesome) para los botones de sumar/restar y para diferenciar visualmente los marcadores de hombres y mujeres. Lógica y Funcionalidad (JavaScript): - Contadores: Debe haber botones independientes de suma y resta para "Hombres" y para "Mujeres". - Pantalla Total: Un marcador principal en el centro que muestre en tiempo real la suma total de ambos contadores. - Texto Dinámico (Singular/Plural): Si el total es 1, debe mostrar exactamente "1 persona". Si el total es 0, o mayor a 1, debe mostrar "X personas" (ej. "0 personas", "5 personas"). - Límite de Aforo: Establece una variable de límite máximo (por ejemplo, 50). Si la suma total alcanza este límite, el sistema debe desactivar los botones de sumar y mostrar un mensaje visual en rojo que diga "Aforo Completo".

3. Prompt de Ajustes Visuales

Pon de fondo una imagen de una discoteca, en el apartado de hombres una imagen de un hombre y en el de mujer una imagen de una mujer, detras del contador general mete una imagen de hombres y mujeres.
