Prompt 1 Requisito Base
Explicación de Pomodoro: Métodos para marcar pautas de trabajo, por ejemplo el horario. Quiero que para el horario puedas elegir los rangos horarios para cada actividad que ponga el usuario. Tiempos de activo y TIEMPOS de Descanso. Que el usuario pueda elegir la hora u horas a las que quiera descansar y poner un cronómetro, para cuando termine suene una alarma. Gestor de Tareas: Agenda con futuras tareas modificables. Tiempo de Sueño: Calcule tiempo dormido según hora de acostarse y despertarse.

Prompt 2 GitHub Pages
Actúa como un Desarrollador Web Full-Stack experto en UI/UX y aplicaciones de productividad. Quiero que crees una aplicación web interactiva completa (HTML5, CSS3 con Tailwind CSS/estilos modernos, y JavaScript modular) llamada "Pomodoro & Life Tracker". Modo oscuro por defecto, responsive y con localStorage. Incluye 4 secciones principales: 1. Temporizador Pomodoro & Horarios Personalizables con alarma sonora (Web Audio API). 2. Gestor de Tareas (To-Do List / Agenda) con CRUD completo. 3. Calculadora y Control de Tiempo de Sueño.
